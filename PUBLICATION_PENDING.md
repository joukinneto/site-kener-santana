# Publicação — ação manual necessária

O repositório está preparado para GitHub Pages, mas permanece privado. Para usar o caminho gratuito aprovado, altere **somente este repositório** para Public em:

Settings → General → Danger Zone → Change repository visibility → Make public.

Depois, o workflow `.github/workflows/pages.yml` poderá ser executado novamente.

Não tornar públicos outros repositórios da JKDD TECH.
