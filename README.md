# Site Psicóloga Kener Santana

Site oficial da **Psicóloga Kener Santana** — CRP 04/39953.  
Atendimento psicológico 100% online, em português, para brasileiros no Brasil e no exterior.

## 🗂 Estrutura do projeto

```
/
├── index.html              # Página principal
├── assets/
│   ├── images/             # Foto da Kener e imagem OG (og-image.jpg)
│   ├── icons/              # favicon.svg
│   └── logo/               # logo.svg
├── css/
│   └── styles.css          # Todos os estilos
├── js/
│   └── main.js             # Interatividade (navbar, FAQ, scroll reveal)
├── README.md
└── .gitignore
```

## ✅ Antes de publicar — checklist

### Obrigatório
- [ ] Adicionar a foto da Kener em `assets/images/kener-santana.jpg`  
      (substitua o bloco placeholder no `index.html`)
- [ ] Substituir todos os `SEUNUMERO` pelo número do WhatsApp no formato internacional  
      (ex.: `5531999999999` para MG)
- [ ] Substituir `SEU_INSTAGRAM_AQUI` pelo @ do Instagram
- [ ] Substituir `SEU_FACEBOOK_AQUI` pelo @ do Facebook
- [ ] Substituir `SEU_DOMINIO_AQUI` pelo domínio oficial (ex.: `kenersantana.psi.br`)
- [ ] Criar `assets/images/og-image.jpg` (1200×630 px) para compartilhamento social
- [ ] Criar página `politica-de-privacidade.html`

### Recomendado
- [ ] Ativar GitHub Pages em **Settings → Pages → Branch: main / root**
- [ ] Configurar domínio personalizado (CNAME)
- [ ] Adicionar Google Analytics ou similar (opcional)

## 🚀 Tecnologias utilizadas

- HTML5 semântico
- CSS3 puro (variáveis, Grid, Flexbox, animações)
- JavaScript vanilla (sem dependências)
- SVG inline para ícones (sem carregar fontes externas)
- Schema.org `MedicalBusiness` para SEO estruturado
- ARIA completo para acessibilidade

## 🌐 Publicação no GitHub Pages

1. Faça o push para a branch `main`
2. Acesse **Settings → Pages**
3. Selecione **Branch: main** e pasta **/ (root)**
4. Salve — o site estará disponível em `https://SEU_USUARIO.github.io/site-kener-santana/`
